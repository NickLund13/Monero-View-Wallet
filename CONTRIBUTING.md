# Contributing

Thank you for helping. Before you open a pull request:

- Read [SECURITY.md](SECURITY.md). Its rules are binding for every change: no
  real keys, seeds, wallet files or key image exports anywhere, no network
  calls beyond the ones rule 5 allows, no tracking, and pinned dependencies.
- After cloning, run `git config core.hooksPath .githooks` once, and before
  pushing run `flutter analyze` and the tests as [README.md](README.md) says.
- Fill in the security and privacy checklist in the pull request.

By opening a pull request you agree that your contribution is licensed under
the GNU General Public License version 3 ([LICENSE](LICENSE)) with the
additional permission in [APP-STORE-PERMISSION.txt](APP-STORE-PERMISSION.txt),
which lets the app be offered on the App Store.

To report a vulnerability, don't open an issue or a pull request: see
[SECURITY.md](SECURITY.md#reporting-a-vulnerability).
